# AWL Study Desk

A dependency-free, GitHub Pages-ready learning site for all 570 word families in Averil Coxhead's Academic Word List.

## Publish on GitHub Pages

Upload the complete `academic-word-lab` folder to a repository. In **Settings → Pages**, publish from the branch and folder containing `index.html`. Keep `assets/awl-data.json` beside the page as shown here.

## Included

- Ten frequency-based sublists and 570 entries
- Part of speech, English meaning, academic-context example, and official word-family forms
- Word and sentence pronunciation through the browser's available `en-NZ` or `en-GB` voice
- Search, device-local learning progress, keyboard navigation, and ten-question multiple-choice practice sets
- Responsive, accessible static files with no server or build step

## Local preview

Serve the folder through any small local web server; opening `index.html` directly will not load the JSON data in some browsers.
