# Shirley’s 海底世界

一個可直接放在 GitHub Pages 上的安靜教室互動海底世界。

## 使用方式

1. 把這個資料夾的所有檔案放進 GitHub repository。
2. 在 repository 的 **Settings → Pages** 選擇從主要分支部署。
3. 用 HTTPS 網址開啟頁面，點右下角的麥克風圖示並允許收音。

麥克風聲音只在瀏覽器內即時換算音量，不會錄音、儲存或上傳。

## 規則

- 海底世界開啟時已有一尾帶隨機編號的紅錦鯉，重新開始後也會保留一尾。
- 音量低於安靜門檻時累積時間。
- 每累積 1 分鐘有效安靜時間，隨機迎來小錦鯉、小蝦、小螃蟹、小海馬、小花枝、小海蔘或小海膽；被噪音打斷的時間不計入。
- 所有住客共用 1–50 隨機編號池；目前仍在海底世界裡的號碼絕不重複。
- 設定面板會顯示鯊魚甦醒、惱怒與攻擊的 dB 門檻；門檻會跟著安靜門檻同步換算。預設為 47 dB 甦醒、54 dB 惱怒、60 dB 攻擊。
- 收音採與原版小靈獸相同的浮點取樣與 95 dB 瀏覽器校正基準；若裝置仍有差異，可在設定面板以「收音校正」微調 ±15 dB。
- 攻擊音量持續約 1.5 秒後，鯊魚會隨機鎖定一位住客；之後有 9 秒冷卻時間。
- 右下角只保留三個小型圖示控制；安靜進度預設隱藏，需要時才展開。
- 設定面板可調整安靜門檻，也可用「迎接一位住客」快速檢查不同生物。
- 「演示鯊魚攻擊」會自動選擇一位游泳住客，完整播放甦醒、追逐、咬下與恢復巡游的動畫，不需要對著麥克風製造噪音。

## 水滴倒數

- 頁面正上方可設定 1–100 分鐘，適合考試、閱讀或安靜活動。
- 播放鍵開始或暫停，回轉箭頭會依目前設定分鐘數重設。
- 倒數進行時，水滴會週期落入海面；時間到會出現擴散漣漪與畫面提示。

## 專案特色

- 無外部圖片、字型、套件或 CDN。
- 水體、光束、氣泡、水草、七種小住客與鯊魚皆由 Canvas 即時繪製；氣泡會受到附近生物的尾流擾動。
- 支援手機、平板、桌面與全螢幕。
- 支援鍵盤焦點、螢幕閱讀器狀態與減少動態偏好。

> 麥克風 API 需要 HTTPS 或 localhost；GitHub Pages 已提供 HTTPS。
